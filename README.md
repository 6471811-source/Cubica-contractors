# CUBICA · Справочник контрагентов

Выгрузка контрагентов из 1С для системы CUBICA.

## Файл

- `contractors.xml` — актуальная выгрузка (XML, 1С 8.2)

## Обновление

1. В 1С: **Внешние обработки → Выгрузка контрагентов → Сохранить как XML**
2. Заменить `contractors.xml` в этом репозитории
3. Через ~1 минуту изменения подхватятся на:
   `https://6471811-source.github.io/Cubica-contractors/contractors.xml`

## Использование

Файл читается из i5 (Счёт-договор CUBICA) через пикер контрагентов (📁).
